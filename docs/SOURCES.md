# Document sources: the adapter model

Confluence and Backstage are not special. Every document source is an **adapter**: a small class that lists the
documents a scope should contain. The ingest engine does everything else the same way for every adapter, so JAMA,
a wiki export on disk, a git repo, SharePoint or an internal API are all the same amount of work: one file.

```
adapter.documents(scope)  ──►  engine: diff versions → batch into that scope's LightRAG → reconcile deletions → commit state
```

## What an adapter is

A subclass of `Source` (`ingest/ingest/sources/base.py`) with a `name` and one required method:

```python
from ingest.sources import Source, Document, ScopeContext

class WikiExportSource(Source):
    name = "wiki-export"

    def __init__(self, options=None):
        super().__init__(options)
        self.root = self.option("root", "/data/wiki")      # non-secret option from `sources:` in scopes.yaml
        self.token = self.env("WIKI_TOKEN")                 # secret from config/stack.env

    def configured(self) -> bool:                           # optional: skip cleanly when not set up
        return bool(self.root)

    def documents(self, ctx: ScopeContext, filter: dict | None = None):
        for page in load_pages(self.root, ctx.config.get("sections", [])):   # ctx.config = the scope's docs: entry
            yield Document(key=page.id, version=page.updated_at, text=page.markdown, title=page.title)
```

| Field | Meaning |
|---|---|
| `key` | stable within (adapter, scope); becomes part of the LightRAG source id |
| `version` | any string that changes when `text` changes: a revision number, an updated-at, a content hash |
| `text` | what LightRAG indexes; prepend a small header (source, path, URL) so answers can cite it |
| `title` | optional, prepended as a heading |

Optional methods: `covers(key, filter)` tells the engine which previously seen keys a filtered (webhook) run
enumerates, so it can delete the ones that disappeared; without a filter everything is covered.

## Where adapters come from

Three discovery paths, checked at startup; a scope only ever references the adapter's `name`:

1. **Built-ins** in `ingest/ingest/sources/`: `confluence`, `backstage`, `git`, `files`.
2. **`plugins/`** in the repo, mounted read-only at `/plugins` (compose bind mount; Kubernetes ConfigMap generated by
   `make gen`). Every `*.py` there is imported; every `Source` subclass in it is registered. This is the intended
   path for org-specific sources. `plugins/jama.py` is a complete example.
3. **Installed packages** declaring an entry point in group `context_stack.sources`, for adapters you want to
   version and test as a proper package:
   ```toml
   [project.entry-points."context_stack.sources"]
   jama = "acme_sources.jama:JamaSource"
   ```
   (install it into the ingest image with a one-line `pip install` in `ingest/Dockerfile`.)

Explicit override: `sources: { name: { type: "pkg.mod:Class" } }` in scopes.yaml points a name at a class.

## Configuration surface

Three places, each with one job, so a new source never touches the ingest code or the shared config module:

| Where | What | Example |
|---|---|---|
| `config/stack.env` | secrets and endpoints, read by the adapter with `self.env()` | `JAMA_URL=…`, `JAMA_TOKEN=…` |
| `config/scopes.yaml` → `sources:` (optional) | non-secret adapter options, `self.option()` | `jama: { page_size: 100 }` |
| `config/scopes.yaml` → scope → `docs:` | what of that source belongs to this scope, `ctx.config` | `jama: { projects: [42] }` |

The `docs:` map is the access-control decision: listing a source under a scope says "everything this adapter yields
for this config may be read by everyone in the scope's groups". The adapter must honour that by skipping anything
with a finer ACL (Confluence page restrictions are the built-in example).

## Developing an adapter

```sh
make source-check SCOPE=payments SOURCE=jama            # runs documents() and prints keys, versions, previews
make source-check SCOPE=payments SOURCE=jama ARGS="--filter '{\"project\": 42}' --limit 5 --full"
```

No LightRAG involved; it only needs the adapter's credentials. When the listing looks right, `make sync` (or
`POST /sync/jama`) ingests it; `GET /sources` on the ingest shows every discovered adapter and whether it is
configured. Webhooks: `POST /webhook/<name>` with a JSON body that your `documents()` understands as `filter`.

## Rules that keep the model safe

- Never yield source code: code belongs to Sourcebot and CodeGraphContext.
- Never yield content whose ACL is narrower than the scope; skip it.
- Keys must be stable across runs; changing the key scheme re-ingests everything.
- Keep `text` as clean text or markdown; strip HTML, keep headings and a header with the source URL.
- Read secrets from the environment only; options and scope config are committed to git.
